# ElMeals | Restaurant Website

A beautifully designed and fully responsive restaurant website built using **HTML, CSS, Bootstrap, JavaScript, and jQuery**.  
The website showcases restaurant services, menu items, chefs, customer testimonials, and contact information — offering a delightful browsing experience for visitors.

## ⚙️ Technologies Used

- **HTML5** – For clean and semantic markup  
- **CSS3** – For styling and responsive design  
- **Bootstrap 5** – For grid system and components  
- **JavaScript (ES6)** – For interactivity and dynamic features  
- **jQuery** – For DOM manipulation and animations  

---

## ✨ Core Features

- Fully responsive and mobile-friendly layout  
- Elegant homepage with hero banner  
- Food menu section  
- Chef and team showcase  
- Customer testimonial carousel  
- Gallery with lightbox effect  
- Contact form and map section  
- Smooth animations and transitions
